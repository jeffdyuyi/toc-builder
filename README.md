# 克苏鲁迷踪车卡器

一个用于《克苏鲁迷踪》（Trail of Cthulhu / TOC）的中文网页建卡与跑团辅助工具。可以填写调查员资料、分配能力、管理点数池、记录装备和战役笔记，并导出角色卡。

[在线使用](https://jeffdyuyi.github.io/toc-builder/) · [源码仓库](https://github.com/jeffdyuyi/toc-builder) · [部署记录](https://github.com/jeffdyuyi/toc-builder/actions)

## 功能

- **角色资料**：头像、职业、动力、心智支柱、角色背景、坚毅之源与联系人。
- **能力配点**：标准、原旨与通俗风格配置；按人数设置调查点数；支持自定义预算、本职折扣和规则警告。
- **跑团辅助**：能力等级与当前点数池分开管理。一般能力支持 D6 检定及点数消耗；调查能力直接记录消耗。
- **状态管理**：基础页与能力页同步心智、坚毅和健康；支持单项调整、恢复能力池及返回建卡编辑等级。
- **装备与笔记**：装备库、可编辑道具表、战役备忘录和基础文字格式。
- **存档与导出**：浏览器本地保存、JSON 完整备份与导入、Markdown 角色资料、包含三个角色页面的 PNG 长图预览与下载。

## 快速使用

1. 打开在线工具，填写调查员资料并选择职业、规则与人数。
2. 在「能力点数」页分配能力等级，查看顶部点数预算和警告。
3. 点击「本地保存」。点数完整且没有警告时进入跑团模式；否则可确认继续完成，或取消并保存草稿。
4. 跑团时能力页数字表示当前池，详情显示原始等级。一般能力可选择消耗点数后掷骰，调查能力通过加减号记录消耗。
5. 使用「JSON」定期下载备份。需要恢复或迁移设备时，点击「导入 JSON」。
6. 点击「图」生成完整角色卡预览，再点击「下载完整角色卡 PNG」；「MD」导出便于复制和分享的文字资料。

「恢复能力池」会将所有当前池恢复至等级，请根据主持人的规则决定使用时机。「编辑等级」会返回建卡并重置当前池，使用前建议保存或导出备份。

## 本地开发

需要 Node.js 22 或更新的兼容版本，以及 npm。项目代码位于 `toc-builder/`。

```sh
git clone https://github.com/jeffdyuyi/toc-builder.git
cd toc-builder/toc-builder
npm ci
npm run dev
```

按终端提示打开本地地址。其他命令：

```sh
npm test        # 数据同步、能力池和存档兼容回归检查
npm run lint    # TypeScript / React 代码规范检查
npm run build   # 类型检查并生成生产版本
npm run preview # 预览生产构建
```

生产文件输出到 `toc-builder/dist/`。图片导出库按需加载，减少首次加载的主包体积。

## GitHub Pages 部署

仓库通过 `.github/workflows/deploy.yml` 自动部署。推送到 `main` 或 `master` 后，GitHub Actions 会安装锁定依赖、执行测试与代码检查、构建并发布到 GitHub Pages；也可在 Actions 中手动触发。

复用此项目时，需要在仓库 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**。Vite 使用相对资源路径，适用于项目子目录托管。

## 存档与兼容说明

- 本地存档保存在浏览器的 `localStorage` 中，绑定浏览器和站点地址。清除站点数据、使用其他浏览器或迁移域名后，本地记录不会自动转移。
- JSON 备份保存角色资料、能力等级、当前池、规则配置和建卡完成状态。PNG 与 Markdown 用于展示，不能替代可恢复的 JSON 存档。
- 同名角色会覆盖同名本地存档。
- 支持旧版存档读取。旧版没有记录的规则配置使用默认值；旧版直接扣减过的原始能力等级无法自动推算，请核对原卡并通过「编辑等级」修正。
- 核心状态以能力页对应等级作为旧数据迁移时的优先值，减少两个页面数值不一致的问题。


## 已知限制

- 规则资料尚未完成逐条对照原书校对，工具提示不能替代主持人的判断。
- 支持自定义点数与主持人批准的规则例外，因此部分警告允许确认后继续。
- 手机端采用单栏角色卡与固定底部导航，支持 320 像素及以上窄屏。
- 本工具不提供账号或云端存档。

点击顶栏「使用预设角色」，查看档案后载入肯尼斯·菲尔、罗杰·菲尔、诺曼·莱特、简·乔伊斯-克利夫兰或诺克斯·梅克皮斯。

- 每次载入都会创建独立副本，保留原始资料、能力等级与满值能力池，直接进入跑团模式。
- 载入会替换当前页面内容，请先保存需要保留的修改；载入本身不会改写浏览器中的存档。后续手动保存仍遵循同名覆盖规则，可先修改姓名以另存。

- 五份根目录 `预设角色卡_*.json` 是内置数据的唯一来源，修改这些文件后重新构建即可更新预设。

## 手机端使用

- 底部可切换角色资料、能力点数、装备笔记与指南规则。
- 顶部保留「使用预设角色」和「本地保存」；导入、导出、读取与等级编辑位于「更多操作」。
- 心智、坚毅和健康支持大按钮增减及直接输入；点击能力名称打开详情与检定弹窗，名称后的「本职」按钮用于独立切换本职标记。
- 装备以独立卡片编辑，装备库分类支持横向滑动。图片导出保持完整三页角色卡排版。

## 刷新恢复与存档备份

编辑后约 0.5 秒自动保存当前草稿，页面隐藏或离开时也会尝试保存。再次打开时可选择「恢复上次草稿」，或先下载草稿 JSON 备份。自动草稿使用独立记录，不覆盖「本地保存」的角色存档；载入角色或开始新角色后，后续编辑会更新当前草稿。

同名角色手动保存会保留上一版，可在「读取本地」列表中选择「读取上一版备份」。备份载入不会直接覆盖正式存档。浏览器存储不可用或空间不足时会明确提示，请及时导出 JSON。所有本地记录均限当前设备、浏览器和网站域名，不能跨设备同步；此前从未保存的丢失内容无法追溯恢复。
