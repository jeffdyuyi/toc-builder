# 三十年代角色头像

来源：乐博睿《克苏鲁迷踪》免费资源页面「三十年代角色头像」
https://labyrpg.com/products/toc/resources.html

本目录内置页面所列 30 张原始 JPEG 图片，按原页面顺序编号。原图地址与 SHA-256 校验值见 manifest.json。应用运行时只读取本项目资源，无需访问乐博睿网站；选择头像时生成较小的 JPEG 数据并随角色存档保存，JSON 备份不依赖外部图片地址。
